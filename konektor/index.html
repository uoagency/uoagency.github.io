۵ کانکتور Claude و طرز وصل کردنشون

دو راه داری: با چند کلیک توی خود اپ Claude، یا با یه پرامپت توی Claude Code.

متن‌هایی که دکمه‌ی «کپی» دارن رو با یه لمس بردار.

قبل از شروع

این‌ها رو آماده کن

  1. VPN روشن، چون Claude و ثبت‌نام این سرویس‌ها از ایران باز نمیشه.
  2. توی پلن رایگان Claude فقط یه کانکتور دلخواه می‌تونی اضافه کنی. برای هر پنج‌تا، پلن پولی لازمه.
  3. Firecrawl و PostHog و Composio پلن رایگان دارن و برای شروع کافیه.
  4. Perplexity کلید API می‌خواد که پولیه. اگه کارت خارجی نداری ازش بگذر، Claude خودش هم توی اینترنت جستجو می‌کنه.

Perplexity و Playwright روی کامپیوتر خودت اجرا میشن، پس اون دوتا فقط با Claude Code وصل میشن.

راه ۱ · بدون کد

از توی اپ Claude

  1. برو Settings و بعد Connectors.
  2. Firecrawl رو توی لیست کانکتورها پیدا کن و Connect رو بزن.
  3. برای PostHog دکمه‌ی Add custom connector رو بزن و این آدرس رو بذار:
    https://mcp.posthog.com/mcp
  4. برای Composio هم همین کارو بکن با این آدرس:
    https://connect.composio.dev/mcp
  5. Connect رو بزن. یه صفحه باز میشه، وارد حسابت شو و اجازه بده.

Client ID و Secret رو خالی بذار. لازم نیست.

راه ۲ · Claude Code

این پرامپتو یه بار پیست کن

این پنج کانکتور (MCP) رو برام توی Claude Code نصب کن. یکی‌یکی برو و قبل از هر کدوم بگو داری چیکار می‌کنی. اگه Node.js نصب نیست، اول اونو نصب کن.

۱. Perplexity: اول ازم کلید API بپرس. اگه گفتم ندارم، ازش بگذر.
claude mcp add --scope user perplexity --env PERPLEXITY_API_KEY=کلید -- npx -y @perplexity-ai/mcp-server

۲. Firecrawl:
claude mcp add --transport http --scope user firecrawl https://mcp.firecrawl.dev/v2/mcp-oauth

۳. PostHog:
claude mcp add --transport http --scope user posthog https://mcp.posthog.com/mcp

۴. Playwright:
claude mcp add --scope user playwright -- npx @playwright/mcp@latest

۵. Composio:
claude mcp add --transport http --scope user composio https://connect.composio.dev/mcp

آخر کار بگو کدوما نصب شدن، و بگو Claude Code رو ببندم و دوباره باز کنم، بعد /mcp رو بزنم و برای Firecrawl و PostHog و Composio توی مرورگر وارد حسابم بشم.

هر پنج‌تا رو با هم نصب می‌کنه. هر جا کلید یا ورود لازم بود، ازت می‌پرسه.

تستش کن

با هر کدوم یه کار واقعی بخواه

«با Perplexity تحقیق کن این هفته توی حوزه‌ی کارم چه خبرهای مهمی بوده و منبع هر خبر رو هم بده.»

«با Firecrawl سایت آدرس سایت رقیب رو بخون و بگو چی می‌فروشه، قیمت‌هاش چنده و صفحه‌ی اولش چی میگه.»

«از PostHog بگو هفته‌ی پیش بیشتر کاربرا کجای سایتم ول کردن و رفتن.»

«با Playwright سایت خودم آدرس رو باز کن، فرم تماس رو با اطلاعات تستی پر کن و بگو کجاش گیر داشت.»

«با Composio ایمیل‌های امروز جیمیلم رو بخون و خلاصه‌شونو توی یه Google Sheet بنویس.»

PostHog فقط وقتی جواب میده که کدش روی سایتت نصب باشه.

یه نکته

کانکتور زیادی Claude رو کند می‌کنه.

هر کانکتور لیست ابزارهاشو می‌ذاره توی حافظه‌ی Claude، حتی وقتی ازش استفاده نمی‌کنی.

فقط اونایی رو روشن نگه دار که این هفته لازمشون داری.

هر هفته یه چیز به‌دردبخور دیگه برای کسب‌وکارت می‌ذاریم.
