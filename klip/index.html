کلیپ GTA 6 با Claude: نصب و استفاده از ClipKaro

لینک ویدیو یا استریم رو میدی، Claude داغ‌ترین لحظه‌ها رو پیدا می‌کنه و کلیپ عمودی ادیت‌شده تحویل میده.

متن‌هایی که دکمه‌ی «کپی» دارن رو با یه لمس بردار.

قبل از شروع

اینا رو چک کن

  1. ClipKaro رایگان و متن‌بازه:
    github.com/allthingsaman/ClipKaro
  2. ویندوز، مک یا لینوکس ۶۴ بیتی با ۸ گیگ رم کافیه. کارت گرافیک NVIDIA با ۴ گیگ خیلی کمک می‌کنه؛ بدونش هر ویدیو ممکنه یکی دو ساعت طول بکشه.
  3. Claude Code با پلن Pro به بالا. پلن پولی نداری؟ بخش «راه مجانی» رو ببین.
  4. VPN روشن، چون Claude و دانلود از یوتیوب از ایران باز نمیشن.

چت معمولی claude.ai به کامپیوترت دسترسی نداره، پس با اون کار نمی‌کنه. باید Claude Code باشه.

نصب (یه بار)

اینو توی Claude Code پیست کن

می‌خوام ابزار ClipKaro رو روی کامپیوترم راه بندازی تا از استریم‌ها و ویدیوهای GTA 6 کلیپ بگیرم.
install this repo: github.com/allthingsaman/ClipKaro
۱. پوشه‌ش رو توی پوشه‌ی کاربرم بساز، نه توی Documents یا Desktop که OneDrive ازشون بکاپ می‌گیره.
۲. چک کن Python 3.12، FFmpeg، Node.js و Git نصب هستن. هر کدوم نبود، دستور نصبشو بهم بده.
۳. install.py رو اجرا کن تا همه‌ی خط‌ها ok بشن.
۴. بگو کارت گرافیک NVIDIA دارم یا نه و هر ویدیو چقدر طول می‌کشه.
۵. برای زیرنویس فارسی فونت Vazirmatn رو اضافه کن و چک کن زیرنویس راست‌چین و چسبیده درمیاد.
۶. آخرش بگو Claude Code رو ببندم و از داخل پوشه‌ی ClipKaro دوباره باز کنم.

هر جا رمز کامپیوترت لازم شد، دستورشو میده خودت بزنی.

یوتیوب روی ویندوز

یه بار فایل کوکی بساز (۲ دقیقه)

  1. توی مرورگری که با یوتیوب واردش شدی، افزونه‌ی Get cookies.txt LOCALLY رو نصب کن.
  2. برو youtube.com، روی افزونه بزن و Export رو بزن.
  3. فایلی که ذخیره شد رو بذار توی پوشه‌ی ClipKaro، کنار فایل run.py.

بدون این فایل یوتیوب ممکنه بگه Sign in to confirm you're not a bot و کار نصفه بمونه.

هر بار

Claude Code رو توی پوشه‌ی ClipKaro باز کن و بنویس

clip this video: لینک ویدیو یا استریم GTA 6

این یه استریم گیمه. ۵ تا کلیپ بین ۲۰ تا ۴۵ ثانیه از هیجانی‌ترین لحظه‌ها بساز: تعقیب، تصادف، شکست خنده‌دار، یا جایی که استریمر داد می‌زنه یا می‌خنده.
هر کلیپ از وسط اکشن شروع بشه، نه با مقدمه. بازی بالای صفحه، صورت استریمر پایینش، اسم استریمر گوشه‌ی کلیپ.
برای هر کلیپ یه تیتر هوک و یه کپشن کوتاه فارسی بنویس و بگو چرا انتخابش کردی.

سهمیه‌ت کمه؟ به جای clip this بنویس quick clip this؛ نصف مصرف رو داره.

راه مجانی

پلن پولی Claude نداری؟ Google Antigravity

  1. Antigravity رو از antigravity.google نصب کن و با حساب گوگلت وارد شو. نسخه‌ی رایگان داره.
  2. یه پوشه رو توش باز کن و همون پرامپت بخش «نصب» رو بهش بده.
  3. بعد پوشه‌ی ClipKaro رو باز کن و همون پرامپت بخش «هر بار» رو بزن.

سهمیه‌ی رایگانش هفتگیه و معمولاً برای یه ویدیو توی هر جلسه کافیه.
