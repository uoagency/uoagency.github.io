Claude دستیار پیجت

نصب اسکیل اینستاگرام، و فایل معرفی پیج که Claude باید اول بخونه.

متن‌هایی که دکمه‌ی «کپی» دارن رو با یه لمس بردار.

قدم ۱

اسکیل‌ها رو بگیر

  1. مخزن متن‌باز instagram-agent-skill روی گیت‌هاب (مجوز MIT)
  2. ۱۲ تا اسکیل داره: ریلز، کپشن، کاروسل، استوری، برنامه‌ی هفته، پروفایل و...
  3. Claude توی ایران VPN می‌خواد.

لینک مخزن: github.com/Jakeschincariol/instagram-agent-skill

قدم ۲

نصبشون کن

  1. Claude Code: پوشه‌ی هر اسکیل رو بذار توی ‎~/.claude/skills‎
  2. Claude در مرورگر: هر پوشه رو زیپ کن و از تنظیمات، بخش Skills، آپلود کن (پلن پولی)
  3. یه بار بنویس «اسکیل‌هات رو لیست کن» که مطمئن بشی نصب شدن.

اگه گزینه‌ی Skills رو توی تنظیماتت نمی‌بینی، نسخه‌ی Claude Code رو امتحان کن.

قدم ۳

فایل معرفی پیج (مهم‌ترین قدم)

پیج من: اسم پیج، چی می‌فروشم
مشتریم: کی، چند سال، چه دردی داره
لحنم: خودمونی / رسمی، این کلمه‌ها رو نمی‌گم: ....
سه تا از بهترین پست‌هام: لینک یا توضیح
کاری که از پیج می‌خوام: فروش / نوبت / فالوور

اینو یه بار بنویس و اول هر کار بهش بده. بدون این، کپشن‌هاش شبیه همه درمیاد.

قدم ۴

اولین درخواست

«با این فایل معرفی، برای هفته‌ی بعد ۵ تا ریلز بنویس. برای هرکدوم سه تا هوک مختلف، متن کامل، و متن روی تصویر.»

خروجی رو بخون و ایراد بگیر. دفعه‌ی دوم خیلی بهتره.

هر هفته یه چیز به‌دردبخور دیگه برای کسب‌وکارت می‌ذاریم.
